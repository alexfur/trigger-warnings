# Changelog

All notable changes to this project are documented here.

## Unreleased

### Added

- An optional terminal setup wizard that validates credentials before storing
  them in the operating system keychain.
- Continuous integration for Python 3.9 through 3.13 on Ubuntu and macOS.
- A package build check and tag-driven PyPI Trusted Publishing workflow.
- Contribution and security guidance.
- A roadmap, and issue forms for a bug report and a feature request.
- Visual proof of the output: a demo GIF, a rendered preview frame and a
  terminal card, all regenerated by `scripts/make_visuals.py` from the bundled
  synthetic fixtures.
- Tests that drive the documented first run with an empty PATH and no network,
  and that fail when the terminal asset stops matching what the tool prints.

### Changed

- The README leads with the outcome. The no-account example is the first
  command, and the setup wizard moved below it, because a credential must not
  block a first successful run.
- A missing FFmpeg now names FFmpeg, not just `ffprobe`, and points at the
  subtitle-only route that needs neither.
- The package summary is the launch tagline.
- The release workflow grants no permission by default, publishes only on a
  `vX.Y.Z` tag and runs `twine check` before uploading.

## 0.3.0

### Added

- OpenSubtitles search and download support using the user's own account.
- An environment-first, opt-in operating-system keychain for credentials.
- A prerequisite report for people and coding agents.
